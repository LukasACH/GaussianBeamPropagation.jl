Sampling beams

To plot a beam quantity along a scan, e.g. along the propagation distance or a varied parameter, it has to be evaluated for many beams. The quantities along x and y jump whenever the principal axes of the beam rotate past ±45° (see radius). sample_beam_continuous follows each principal axis instead, which gives continuous curves.

using GaussianBeamPropagation

λ = 1.03e-6
# The principal axes rotate by 180° over the scan
beams = [
    Beam(λ, Waist(4e-3), Waist(2e-3); φ=α) for α in range(0, π; length=7)
]

GaussianBeamPropagation.sample_beam — Function
sample_beam([f=radius,] beams)

Evaluate f (e.g. radius, divergence or phase_curvature) for each beam in beams.

Returns a named tuple (; x, y, φx, φy) of vectors: the values along both principal axes and the orientation of these axes, with φx ∈ [0, π) and φy = φx + π/2 (modulo π).

GaussianBeamPropagation.sample_beam_continuous — Function
sample_beam_continuous([f=radius,] beams)

Like sample_beam, but follows each principal axis continuously through beams, for example along a propagation distance or a scanned parameter.

The quantities along x and y (see radius) jump whenever the principal axes rotate past ±45°, because x is always the axis closest to the x direction. Here, the axes are swapped back whenever that happens, and the angles are unwrapped, such that x, y, φx and φy are continuous for a continuous sequence of beams.

source
GaussianBeamPropagation.sample_beam_at_angle — Function
sample_beam_at_angle([f=radius,] beams, angle)

Like sample_beam, but projects the values onto two fixed perpendicular directions, at angle and angle + π/2, instead of the principal axes of each beam.
